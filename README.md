# 747Disco-CRM-EMAIL-SCAN

## Repository Contents

### 1. 747 Disco CRM Plugin (WordPress)
Plugin CRM completo per la gestione dei preventivi della location 747 Disco.

**File principale:** `747disco-crm.php`

### 2. YouTube Karaoke Extension (Chrome Extension) 🎤
Estensione per Google Chrome che salta automaticamente le pubblicità di YouTube e trasmette video a pieno schermo sul secondo monitor per eventi karaoke.

**Directory:** `youtube-karaoke-extension/`

**Caratteristiche:**
- 🚫 Salta automaticamente le pubblicità di YouTube
- 📺 Fullscreen su secondo monitor con un clic
- ⌨️ Scorciatoia da tastiera: Ctrl+Shift+K
- 🎛️ Interfaccia popup intuitiva
- 💾 Impostazioni persistenti

**Documentazione completa:** Vedi `youtube-karaoke-extension/README.md`

**Quick Start:**
1. Vai su `chrome://extensions/`
2. Attiva "Modalità sviluppatore"
3. Carica la cartella `youtube-karaoke-extension`
4. Apri un video YouTube e premi `Ctrl+Shift+K`
